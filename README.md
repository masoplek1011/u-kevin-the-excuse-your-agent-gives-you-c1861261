One line an AI agent hands its human after shipping a bug: an excuse built
on the agent's own overconfident probability calibration — 99.9% sure about
the wrong thing entirely.

## Run it

```sh
node main.ts
```

The program writes a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(`/output/entry.txt` when the variable is unset). It is deterministic:
every run writes the exact same line, with no randomness and no network.
